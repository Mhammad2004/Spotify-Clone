🎵 Spotify Clone (Frontend Only)

A frontend clone of Spotify built with HTML, CSS, and JavaScript.
This project replicates the look and feel of Spotify’s web player with a working music player bar, playlist functionality, and responsive design.

✨ Features

🎧 Custom music player with play, pause, next, and previous controls

📊 Seekbar that updates as the song plays

📂 Limited songs stored locally in a songs folder (demo purpose only)

🎶 Access songs by clicking the “Your Playlist” button → loads available songs from the songs folder

📱 Responsive design that adapts to different screen sizes

🔐 Login and Sign Up pages styled to look like Spotify’s originals

🛠️ Tech Stack

HTML5

CSS3 (Flexbox, Grid, Responsive Design)

Vanilla JavaScript
